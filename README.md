# Bidirectional-Bangla-Braille-Device
ESP32-based bidirectional Bangla Braille device. It turns six-dot Braille typed on push buttons into Bangla text on an OLED with spoken audio, and turns Bangla text sent from a web page into tactile Braille on a six-solenoid cell. EEE 416 project, BUET, Group C2.04.
